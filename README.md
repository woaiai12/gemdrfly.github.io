# Gemdrfly · IT 技术服务网站

一个中文、能接单的静态站：系统运维 + IT 技术服务定位。

## 页面
- `index.html` —— 首页（定位 + 服务 + 关于 + 联系）
- `services.html` —— 服务与报价
- `cases.html` —— 案例
- `blog.html` —— 文章
- `contact.html` —— 联系
- `styles.css` —— 全部样式
- `CNAME` —— 自定义域名 gemdrfly.com

## 上线前你要改的
1. `contact.html` 里把「微信号：待填」「邮箱：待填」换成真实联系方式
2. `cases.html` 里把两个占位案例换成真实案例
3. `index.html` 里「关于我」如需露出真实姓名/城市，可自行补充

## 部署
把整个文件夹内容覆盖到你的 GitHub 仓库 `woaiai12/gemdrfly.github.io` 根目录（main 分支），GitHub Pages 会自动部署到 https://gemdrfly.com。
